# گزارش آزمون‌های دستی نسخهٔ محلی

## پروژه: طبقه‌بندی وضعیت لوله

این گزارش بر اساس خروجی‌های CMD، پاسخ‌های API، اسکرین‌شات‌های Streamlit و نتایج پرس‌وجوهای SQL که در جریان اجرای پروژه ارسال شده‌اند تنظیم شده است. این آزمون‌ها در محیط محلی کاربر انجام شده‌اند؛ تهیهٔ این گزارش به معنی اجرای مستقل یا خودکار آزمون‌ها در محیطی دیگر نیست.

مسیر بررسی‌شده: ورود اطلاعات در Streamlit، ارسال درخواست به FastAPI، اجرای مدل آموزش‌دیده، ذخیرهٔ نتیجه در SQL Server و نمایش پاسخ در فرم.

## نتایج مشاهده‌شده

| آزمون | نتیجهٔ مورد انتظار | نتیجهٔ مشاهده‌شده | وضعیت |
|---|---|---|---|
| آماده‌بودن مدل در API | پاسخ موفق از `/health` و بارگذاری مدل | `status: ok`، `model_loaded: true` و `sklearn_version: 1.6.1` | موفق |
| درخواست معتبر در API | دریافت پاسخ پیش‌بینی برای ورودی نمونه | HTTP `200`؛ کلاس `Moderate`؛ امتیازها: `Critical = 0.315`، `Moderate = 0.66` و `Normal = 0.025` | موفق |
| ارسال همان ورودی از فرم | نمایش نتیجهٔ سازگار با API | `Moderate` با امتیاز `66.00%` | موفق |
| ذخیرهٔ یک درخواست معتبر پس از افزودن ثبت SQL | ایجاد رکورد و نمایش شناسهٔ ثبت | پیام ذخیره با `PredictionId = 1`؛ وجود همان رکورد با پرس‌وجوی مستقل در SSMS تأیید شد | موفق |
| تطبیق دادهٔ ذخیره‌شده | یکسان‌بودن ورودی و نتیجه با درخواست نمونه | `Material = Carbon Steel`، `Material_Loss_Percent = 31.72`، `PredictedCondition = Moderate` و امتیاز `Moderate = 0.66` | موفق |
| ردکردن ضخامت صفر | خطای اعتبارسنجی برای `Thickness_mm = 0` | HTTP `422`؛ محل خطا `body → Thickness_mm`؛ پیام `Input should be greater than 0` | موفق |
| شمارش رکوردها پس از درخواست نامعتبر | اضافه‌نشدن رکورد پیش‌بینی در این آزمایش | تعداد رکوردهای `dbo.PredictionLogs` همچنان `1` بود | موفق |

آزمایش درخواست معتبر در API پیش از اضافه‌شدن قابلیت ثبت SQL انجام شد. پس از فعال‌شدن ثبت SQL، درخواست نمونه از فرم ارسال شد و رکورد شمارهٔ ۱ به‌طور مستقل در دیتابیس بررسی شد.

## ورودی نمونهٔ معتبر

```json
{
  "Pipe_Size_mm": 800,
  "Thickness_mm": 15.48,
  "Material": "Carbon Steel",
  "Grade": "ASTM A333 Grade 6",
  "Max_Pressure_psi": 300,
  "Temperature_C": 84.9,
  "Corrosion_Impact_Percent": 16.04,
  "Material_Loss_Percent": 31.72,
  "Time_Years": 2
}
```

شناسهٔ مدل در پاسخ و رکورد ذخیره‌شده: `rf-200-99fe7338cf89`

زمان ثبت رکورد شمارهٔ ۱، بر مبنای UTC: `2026-10-18 11:13:34.736`

در آزمایش نامعتبر، تنها مقدار `Thickness_mm` نسبت به نمونهٔ بالا به `0` تغییر داده شد.

## دامنه و محدودیت‌های تأیید

این مشاهدات عملکرد مسیر اصلی برنامه را برای یک ورودی معتبر و یک ورودی نامعتبر نشان می‌دهند. نتیجهٔ موفقِ این آزمون‌ها به معنی پوشش کامل آزمون‌های نرم‌افزاری، ارزیابی مستقل دقت مدل، تأیید امنیت انتشار عمومی یا آماده‌بودن برای بهره‌برداری صنعتی نیست. آزمون خودکار فراگیر، قطع دیتابیس، درخواست‌های هم‌زمان و جلوگیری از ثبت تکراری، در این گزارش تأیید نشده‌اند.

عدد `66%` امتیاز کلاس انتخاب‌شده برای ورودی نمونه است؛ نه دقت کل مدل یا احتمال اعتبارسنجی‌شدهٔ خرابی واقعی. مدل فعلی از `Material_Loss_Percent` به‌عنوان ورودی استفاده می‌کند و در این پروژه برای طبقه‌بندی آموزشی وضعیت فعلی ارائه شده است، نه پیش‌بینی اعتبارسنجی‌شدهٔ خرابی آینده یا صدور دستور تعمیر.

Tableau پیش‌تر برای تحلیل توصیفی داده استفاده شده است. این گزارش اتصال خودکار آن به سوابق SQL یا آزمون تازه‌ای برای داشبورد Tableau را تأیید نمی‌کند.

## وضعیت این نسخه

مسیر محلی فرم تا مدل و ذخیرهٔ SQL برای سناریوی نمونه، و ردکردن ضخامت صفر بدون افزایش تعداد رکوردهای ذخیره‌شده، با شواهد ارسال‌شده تأیید شدند. انتشار اینترنتی در این مرحله انجام نشده است.
